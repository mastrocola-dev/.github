# mastrocola.dev

> AI in production on backends that can't fail. A living portfolio built as a real company.

**[mastrocola.dev](https://mastrocola.dev)** is a software engineering organization built from scratch to show, in public, how to put AI into systems where mistakes cost money: agents that run on event-driven backends, spend inside a budget, cite their evidence, and hand the final decision to a person. Every architectural decision is documented and everything runs on real cloud infrastructure.

Created and maintained by [Marcio Mastrocola Alcantara](https://www.linkedin.com/in/marcio-mastrocola), software architect with twenty years in mission-critical backends, data engineering and fintech.

## Why this exists

Most portfolios are a pile of tutorial clones. This one is structured like an actual company:

- **Multi-repo architecture** with clear domain boundaries
- **Infrastructure as code** provisioning real Azure resources through OIDC-authenticated pipelines, with no secrets in GitHub
- **Documented decisions**: every significant choice has an ADR explaining the trade-offs
- **AI with guardrails**: tool allowlists, structured output, token and spend budgets, traces, human approval before any side effect

The site answers for itself: visitors can ask how it is built, and an AI agent replies from the architecture documentation, citing the records it used ([how that runs](https://github.com/mastrocola-dev/docs/blob/main/architecture/agent-runtime.md)).

The goal is twofold: showcase architectural competence, and keep the door open for this to become a real product company.

## Tech stack

**Backend:** Node.js (TypeScript), Python
**Architecture:** Event-driven services
**Cloud:** Microsoft Azure (Functions, Service Bus, Table Storage, Key Vault, Static Web Apps), Cloudflare, Terraform, GitHub Actions with OIDC federation
**AI:** Anthropic API, Model Context Protocol
**Data & messaging:** SQL Server, PostgreSQL, MongoDB, RabbitMQ, Kafka, Apache Airflow

## Roadmap

Done:

- [x] Azure infrastructure as code, one workload identity per repository, Key Vault as the only secret store
- [x] Public site live at [mastrocola.dev](https://mastrocola.dev), hosting and DNS as code
- [x] Agent host with MCP tools, guardrails, structured output and traces (`service-agent`, `mcp-docs`)
- [x] Agent in the pipeline: the site's decision index is generated by the agent and reviewed in the pull request
- [x] Agent runtime in production: queue-based jobs behind rate limiting, quotas and a daily budget

Next:

- [ ] Site rebuilt around case studies, readable without JavaScript
- [ ] **Household finance ledger**, in daily use by its two real users: Claude connector over Entra OAuth, every change audited, no payment ever executed
- [ ] Public demo: a read-only connector over fictional data that anyone can add to Claude
- [ ] Bank statement import: rules reconcile first, an agent suggests the rest, a person confirms; evaluation suite in CI
- [ ] App and portal with single sign-on, the services behind it made private
- [ ] Tracing and alerts across services, with cost per operation on a dashboard
